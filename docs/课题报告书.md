# UV投影映射技术研究课题报告书

## 1. 课题背景

### 1.1 研究动机

本课题针对三维计算机图形学中的UV映射传递问题展开深入研究。在游戏开发、影视制作和工业设计等领域，高模（高精度网格）需要通过网格简化技术生成低模（低精度网格）用于实时渲染。传统工作流程要求高低模使用同一张贴图以节省内存和带宽，这需要将高模的UV坐标准确传递到低模上。

### 1.2 技术挑战

当前UV映射传递面临以下关键技术挑战：

1. **拓扑差异问题**：高模经过大幅简化后，低模的拓扑结构与高模存在显著差异，顶点之间的对应关系不再是一一映射。

2. **UV岛边界处理**：高模的UV空间通常被分割成多个不连续的"岛"，这些岛的边界在3D空间中构成复杂的接缝结构。在低模上准确重建这些接缝位置极具挑战性。

3. **几何对应与纹理对应的不一致性**：基于几何距离的最近点对应不能保证纹理空间的连续性，特别是在对称结构、重复纹理区域以及薄壁几何中。

4. **数值稳定性问题**：传统的线性最小二乘方法在处理病态矩阵时容易产生数值不稳定，导致UV坐标出现翻转、拉伸或重叠。

5. **计算效率与质量平衡**：在保证质量的前提下，需要算法具备足够高的计算效率以支持工业级应用。

### 1.3 现有技术局限

传统的UV映射方法主要包括：
- **直接参数化方法**：如LSCM、ABF等，但无法继承高模的UV布局
- **重烘焙方法**：需要重新生成贴图，违背"共用贴图"的前提
- **简单投影方法**：精度不足，无法处理复杂拓扑
- **基于距离场的投影**：计算成本高，且在复杂几何下容易产生穿透错误

现有方法在处理大幅简化的低模时，经常出现UV翻转、纹理错位、接缝撕裂等质量问题，缺乏理论完备性和工程鲁棒性。

## 2. 技术方案

### 2.1 核心创新思路

本项目提出了一套完整的UV映射传递技术框架，核心创新在于：

1. **梯度场传递替代点对点映射**：不再直接传输UV坐标值，而是传输UV的局部微分结构（Jacobian场），从数值拟合问题转变为微分几何问题。

2. **拓扑对齐与语义传递**：通过高模UV岛分析、语义传递和拓扑切缝，在低模上重建与高模一致的UV空间分割结构。

3. **稳健统计与自适应正则化**：采用IRLS、Huber损失、自适应平滑等机制，提高算法对噪声和异常值的鲁棒性。

4. **分层求解策略**：结合线性初始化和非线性精化，既保证计算效率又确保数值质量。

### 2.2 技术架构

项目实现包含三条主要技术路线：

**Method2：梯度-泊松方法（当前主线）**
- 核心思想：将高模UV的Jacobian场传递到低模，通过泊松方程重建低模UV坐标
- 主要流程：UV岛分析 → 拓扑切缝 → 稳健对应 → Jacobian聚合 → 泊松求解 → 后处理对齐

**Method4：Jacobian-可注入非线性方法**
- 核心思想：在Method2初始化基础上，通过带可逆性约束的非线性优化精化UV
- 主要流程：Method2初始化 → Symmetric Dirichlet能量构建 → 预修复 → 非线性优化 → 局部patch精化

**Method2.5：投影Jacobian-可注入方法（实验性）**
- 结合Method2的残差场投影器和Method4的非线性求解器

### 2.3 关键技术创新

#### 2.3.1 基于Halfedge的UV岛语义传递
- 基于UV连续性而非几何连通性的高模UV岛定义
- 四点软投影策略进行低模语义传递
- 基于置信度的优先级传播和ICM局部重标记
- 吸收小连通块减少碎片化

#### 2.3.2 稳健Jacobian聚合
采用IRLS、Huber损失和分位数/MAD异常检测的组合策略

#### 2.3.3 自适应平滑权重
根据Jacobian聚合的方差动态调节平滑强度，在高置信度区域强平滑，在低置信度区域弱平滑。

#### 2.3.4 Symmetric Dirichlet能量
Method4采用对称狄利克雷能量作为正则项，具有防止翻转、惩罚负面积、双向约束拉伸和压缩等优良性质。

## 4. 实验结果

### 4.1 实验设置

**测试数据集**：
- Medium难度：corgi_traveller.glb
- Hard难度：massive_nordic_coastal_cliff、aksfbx、rotarycannon

**评估指标**：
- uv_flip_ratio：翻转三角形比例
- uv_bad_tri_ratio：不合格三角形比例
- uv_color_reproj_l1/l2：纹理颜色重投影误差
- uv_stretch_p95/p99：UV拉伸度分位数

### 4.2 主实验结果

#### Stage2 Gate对比（massive模型）

| 方法 | 成功率 | bad_tri均值 | color L1均值 | flip均值 |
|------|--------|-------------|--------------|----------|
| Baseline (legacy) | 100% | 0.852472 | 0.100359 | 0.838496 |
| Method2 | 100% | 0.569226 | 0.113492 | 0.557970 |
| Method4 | 100% | 0.569417 | 0.113923 | 0.557981 |

**关键发现**：
- Method2在bad_tri指标上比基线改善33.23%
- Method4在bad_tri指标上比基线改善33.20%
- 两种方法都显著降低了UV翻转比例（约33%改善）

### 4.3 失败案例分析

主要失败模式包括：
1. 极低模问题：简化率过高导致对应歧义
2. 复杂接缝：多重UV岛边界难以准确重建
3. 薄壁几何：双向射线容易穿透到错误面
4. 对称结构：几何相似但UV不同的区域容易混淆

### 4.4 性能分析

**计算时间**（H100 GPU，512分辨率）：
- 网格重建：0.52秒
- UV投影（Method2）：0.17秒
- UV精化（Method4）：额外0.05-0.10秒
- 总计：<1秒

## 5. 项目总结

### 5.1 技术贡献

**理论层面**：
- 从UV坐标拟合转向Jacobian场传递，建立了更坚实的数学基础
- 引入Symmetric Dirichlet能量保证UV参数化的可逆性
- 提出了基于拓扑对齐的UV语义传递框架

**工程层面**：
- 实现了完整的UV映射传递pipeline，支持多种回退策略
- 建立了可复现的实验框架和评估体系
- 提供了OpenGL交互式预览工具和Mitsuba3渲染集成

**应用层面**：
- 显著改善了UV质量，特别是翻转比例降低约33%
- 支持复杂工业资产的处理
- 为后续研究提供了坚实的技术基础

### 5.2 局限性分析

1. **对应问题的不适定性**：在拓扑差异大或几何复杂的情况下，几何对应仍然存在根本性的歧义
2. **UV岛依赖**：算法高度依赖高模UV的质量，对原始UV的distortion敏感
3. **计算成本**：虽然经过GPU优化，但在极大模型上仍需数秒时间
4. **参数敏感性**：部分参数需要针对不同资产调整

### 5.3 未来方向

1. **深度学习增强**：使用神经网络预测初始对应，减少几何对应的歧义性
2. **最优传输框架**：通过OTM-UV方法解决对应的多值性和不确定性
3. **自适应拓扑细化**：在关键接缝位置自动细化低模拓扑
4. **迭代优化框架**：实现完整的迭代refinement

### 5.4 结论

本项目针对UV映射传递这一经典但极具挑战性的几何处理问题，提出了基于Jacobian场传递和拓扑对齐的完整解决方案。通过Method2的线性泊松方法和Method4的非线性精化方法，在保持计算效率的同时显著改善了UV质量。

虽然在几何对应的不适定性等根本问题上仍存在局限性，但当前成果已经展现了微分几何方法和稳健统计技术在UV传递问题上的巨大潜力。未来的研究应继续深化这些方向，并结合学习型方法，最终实现理论完备、工程鲁棒的UV自动化传递系统。
